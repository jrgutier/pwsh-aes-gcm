# PowerShell AES-256-GCM Module

A PowerShell module for AES-256-GCM authenticated encryption that works on air-gapped Windows machines (Windows 7, 10, and 11) using only native .NET capabilities.

## Features

- **Air-gapped compatible**: No external dependencies - uses only native Windows .NET Framework/Core
- **Automatic fallback**: Detects available .NET runtime and uses optimal implementation
  - Modern: `System.Security.Cryptography.AesGcm` (.NET Core 3.0+, PowerShell 7+)
  - Legacy: Windows BCrypt CNG via P/Invoke (.NET Framework 3.5+, PowerShell 5.1)
- **AES-256-GCM**: Industry-standard authenticated encryption
- **Hex string interface**: All inputs and outputs are hexadecimal strings
- **Automatic nonce generation**: Secure random nonces generated by default
- **AAD support**: Additional Authenticated Data for enhanced security
- **Wycheproof tested**: Validated against Google's cryptographic test suite (66/105 tests passing, 62.86%)

## Installation

1. Copy the entire module directory to your target system
2. Import the module:

```powershell
Import-Module .\AesGcm.psd1
```

## Usage

### Generate a Key

```powershell
$key = New-AesGcmKey -AsHex
Write-Host "Key: $key"
```

### Encrypt Data

```powershell
# Encrypt with automatic nonce generation
$plaintext = "48656c6c6f20576f726c64"  # "Hello World" in hex
$result = ConvertTo-AesGcmEncrypted -Key $key -Plaintext $plaintext

Write-Host "Ciphertext: $($result.Ciphertext)"
Write-Host "Tag: $($result.Tag)"
Write-Host "Nonce: $($result.Nonce)"
```

### Decrypt Data

```powershell
$decrypted = ConvertFrom-AesGcmEncrypted `
    -Key $key `
    -Ciphertext $result.Ciphertext `
    -Tag $result.Tag `
    -Nonce $result.Nonce

Write-Host "Decrypted: $decrypted"
```

### With Additional Authenticated Data (AAD)

```powershell
# Encrypt with AAD
$aad = "aabbccddeeff"
$result = ConvertTo-AesGcmEncrypted `
    -Key $key `
    -Plaintext $plaintext `
    -AdditionalData $aad

# Decrypt with AAD (must match encryption AAD)
$decrypted = ConvertFrom-AesGcmEncrypted `
    -Key $key `
    -Ciphertext $result.Ciphertext `
    -Tag $result.Tag `
    -Nonce $result.Nonce `
    -AdditionalData $aad
```

### Explicit Nonce

```powershell
# Generate a custom nonce
$nonce = New-AesGcmNonce -Size 12 -AsHex

# Use explicit nonce for encryption
$result = ConvertTo-AesGcmEncrypted `
    -Key $key `
    -Plaintext $plaintext `
    -Nonce $nonce
```

## API Reference

### Cmdlets

#### `New-AesGcmKey`
Generates a cryptographically secure 256-bit key.

**Parameters:**
- `-AsHex` (switch): Return key as hexadecimal string

**Returns:** Byte array or hex string

#### `New-AesGcmNonce`
Generates a cryptographically secure nonce/IV.

**Parameters:**
- `-Size` (int): Nonce size in bytes (default: 12 for 96-bit)
- `-AsHex` (switch): Return nonce as hexadecimal string

**Returns:** Byte array or hex string

#### `ConvertTo-AesGcmEncrypted`
Encrypts plaintext using AES-256-GCM.

**Parameters:**
- `-Key` (string, required): 64-character hex string (256-bit key)
- `-Plaintext` (string, required): Hex string to encrypt (can be empty)
- `-Nonce` (string, optional): Hex string nonce (auto-generated if omitted)
- `-AdditionalData` (string, optional): Hex string AAD

**Returns:** Hashtable with `Ciphertext`, `Tag`, and `Nonce` (all hex strings)

#### `ConvertFrom-AesGcmEncrypted`
Decrypts ciphertext using AES-256-GCM.

**Parameters:**
- `-Key` (string, required): 64-character hex string (256-bit key)
- `-Ciphertext` (string, required): Hex string to decrypt (can be empty)
- `-Tag` (string, required): 32-character hex string (128-bit tag)
- `-Nonce` (string, required): Hex string nonce
- `-AdditionalData` (string, optional): Hex string AAD (must match encryption)

**Returns:** Decrypted plaintext as hex string

**Throws:** Exception if authentication tag verification fails

#### `Test-AesGcmImplementation`
Runs Wycheproof cryptographic test vectors.

**Parameters:**
- `-TestVectorPath` (string): Path to aes_gcm_test.json
- `-Quick` (switch): Run subset of tests

**Returns:** Hashtable with test results

## Security Considerations

1. **Key Management**: Store keys securely. Never hardcode keys in scripts.
2. **Nonce Reuse**: Never reuse a nonce with the same key. Always use automatic generation or ensure uniqueness.
3. **Authentication**: GCM provides authenticated encryption - always verify the tag during decryption.
4. **AAD**: Use AAD for context-binding (e.g., user ID, timestamp) to prevent certain attacks.
5. **Air-gapped Systems**: This module requires no internet connectivity or external dependencies.

## Limitations

- Only supports AES-256 (not AES-128 or AES-192)
- Recommended nonce size is 96 bits (12 bytes)
- Some edge cases with non-standard IV sizes may fail (see test results)
- Windows BCrypt implementation limitations apply to legacy mode

## Implementation Details

### Modern Implementation (`AesGcmNative.ps1`)
Uses `System.Security.Cryptography.AesGcm` class available in:
- .NET Core 3.0+
- .NET 5, 6, 7, 8+
- PowerShell 7+

### Legacy Implementation (`AesGcmLegacy.ps1`)
Uses P/Invoke to Windows CNG BCrypt APIs:
- `BCryptOpenAlgorithmProvider`
- `BCryptSetProperty` (GCM mode)
- `BCryptGenerateSymmetricKey`
- `BCryptEncrypt` / `BCryptDecrypt`
- Handles `BCRYPT_AUTHENTICATED_CIPHER_MODE_INFO` structure

Compatible with:
- .NET Framework 3.5+
- Windows Vista and later
- PowerShell 5.1
